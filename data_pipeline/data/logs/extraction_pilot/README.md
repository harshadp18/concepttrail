# Extraction pilot logs (generated, Git-ignored)

| File | Contents |
|---|---|
| `pilot_selection.json` | Numeric selection signals for every eligible document and the 10 chosen slots, with reasons |
| `run_manifest.json` | Versions, OCR environment, per-document authorisation decisions, SHA-256 before and after, artifact paths and reuse flags |
| `events.jsonl` | One event per selected document |
| `quality_report.json` | Per-document extraction metrics and findings (no textbook text) |
