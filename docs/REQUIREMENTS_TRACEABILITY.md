## Status definitions

- `implemented and tested`: code exists and repeatable tests pass.
- `implemented but untested`: code exists but acceptance evidence is absent.
- `partially implemented`: only part of the described path exists.
- `documented only`: requirement is present in the README/specification but no verified implementation evidence was supplied.
- `missing`: required component/decision is absent from supplied materials.
